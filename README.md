#🎮 AGame

AGame은 사용자가 자신의 최고의 게임! AGame을 위해서 맞춤 인터벌 음악을 제공해줍니다.

직접 커스텀한 타이머 간격에 따라 음악을 자동으로 전환하며 재생해주는 Spotify 기반 인터벌 뮤직 앱입니다. 운동, 집중, 스트레칭 등 다양한 목적에 맞는 음악 루틴을 구성할 수 있습니다.

📱 주요 기능
🎧 Spotify 연동: Premium 계정 로그인 후 음악 재생 가능

⏱️ 인터벌 타이머: 사용자 지정 구간(예: 3분/2분)에 따라 재생 목록 자동 전환

🔀 AI 추천 모드: 상황(공부, 운동 등)에 맞는 테마형 재생 목록 자동 생성

💾 패턴 저장/불러오기: 자주 사용하는 루틴을 저장하고 쉽게 불러올 수 있음

🔄 재생 목록 교차 전환: 두 개의 재생 목록을 정해진 시간 간격으로 반복 전환

🛠️ 기술 스택
프론트엔드
React (Vite + Tailwind)

React Router, Zustand

Spotify Web Playback SDK

백엔드
Spring Boot (Java 17)

Spotify Web API 연동

JWT 기반 사용자 인증

배포
AWS EC2 (Ubuntu 22.04)

Nginx + PM2 + Docker (예정)

🚀 사용 예시
Spotify 로그인 → 원하는 재생 목록 선택

인터벌 구간 설정 (예: 3분/2분)

재생 시작 → 두 재생 목록이 자동 전환되며 플레이

AI 모드 선택 시, 분위기에 맞는 추천 플레이리스트 자동 설정

📌 향후 계획
DB 저장 기반 유저별 패턴 관리

백엔드 기반 추천 시스템 고도화

모바일 뷰 최적화 및 앱화(PWA)
